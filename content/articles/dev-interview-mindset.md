# Developer Interview Mindset

## 🎯 Meta goals
1. Understand the problem you’re solving and why it matters.
2. Decide how to implement it (tools, data structures, algorithms).
3. Practice hands-on to internalize the solution.
4. Refine afterwards, applying theoretical improvements and optimizations.

## 🔍 Translating problems
- Take the prompt from whiteboard to abstract model, then to code, then to the most suitable algorithm.
- Identify essential elements, relationships, and constraints before coding.

## 📊 Data ordering
- Check whether the input data is already sorted; it affects algorithm choice (e.g., enabling binary search vs. needing sort step).

## ⏱ Worst-case analysis
- Always consider the worst scenario per dataset; it’s more critical than the best case for reliable systems.
- Evaluate time and space complexity limits.

## 📦 Data location
- Reconsider where data lives; organise structures so frequently accessed items are easy to reach (indexes, hash tables, caching strategies).

## 🔁 Continuous improvement
- After delivering a solution, revisit for better approaches using theory, patterns, and best practices.

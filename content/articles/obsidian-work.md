## Introduction

Goal: run a Zettelkasten-driven vault with reliable sync, fast capture from Kindle/Samsung Notes/MyMind, and repeatable daily/weekly reviews.

## Main Content

### Vault structure and templates

- Use templates with front-matter to index notes and keep metadata consistent.
    
- Adopt concise headers and start notes with a TL;DR when useful.
    
- Example folders for interview prep show a clear pattern you can reuse for other domains.
    

### Sync strategy (OneDrive example)

- Identify the most recent vault folder on each device, prefer a single root.
    
- Delete stale duplicates after copying any newer files you still need. Use diff tools if needed.
    

### Daily and weekly notes

- Core **Daily notes** for journals and logs. Configure location and format in settings. ([Obsidian Help](https://help.obsidian.md/plugins/daily-notes?utm_source=chatgpt.com "Daily notes - Obsidian Help"))
    
- **Periodic Notes** to auto-create weekly notes and integrate with Calendar. ([Obsidian Stats](https://www.obsidianstats.com/plugins/periodic-notes?utm_source=chatgpt.com "Periodic Notes - Create/manage your daily, weekly, and monthly notes in Obsidian"))
    
- Keep reviews lightweight: Daily at 21:00 and Weekly on Sunday if using TickTick in parallel.
    

### Plugin stack (purpose first)

- **Dataview**: dashboards and queries over notes. ([Obsidian Stats](https://www.obsidianstats.com/plugins/dataview?utm_source=chatgpt.com "Dataview - A data index and query language over Markdown files, for https://obsidian.md/."))
    
- **Templater**: templates + JS for automation. ([GitHub](https://github.com/SilentVoid13/Templater?utm_source=chatgpt.com "GitHub - SilentVoid13/Templater: A template plugin for obsidian"))
    
- **Tasks**: reminders and rollups across the vault. ([Obsidian](https://publish.obsidian.md/hub/02%20-%20Community%20Expansions/02.05%20All%20Community%20Expansions/Plugins/obsidian-tasks-plugin?utm_source=chatgpt.com "obsidian-tasks-plugin - Obsidian Hub - Obsidian Publish"))
    
- **Daily Notes / Calendar / Periodic Notes**: time-based notes. ([Obsidian Help](https://help.obsidian.md/plugins/daily-notes?utm_source=chatgpt.com "Daily notes - Obsidian Help"))
    
- **QuickAdd** and **Highlightr**: fast capture and visual emphasis.
    
- Optional: **Note Refactor**, **Smart Connections/Copilot** for exploratory linking.
    

### Capture and imports

- Kindle, Instapaper, articles → **Readwise Official** plugin to sync highlights into Obsidian. ([GitHub](https://github.com/readwiseio/obsidian-readwise?utm_source=chatgpt.com "GitHub - readwiseio/obsidian-readwise: Official Readwise plugin for Obsidian"))
    
- Samsung Notes exports pair well with the vault; consider this for handwritten inputs.
    
- Web snippets and ideas from **MyMind** and YouTube references are tracked for processing.
    

### Canvas and advanced markdown

- Use **Canvas** to connect related notes visually.
    
- Keep a reference on Obsidian markdown quirks if needed.
    

### TickTick vs Obsidian

- TickTick is simpler for reminders and recurring tasks. Keep Daily/Weekly there if you prefer minimal setup.
    
- Obsidian gives richer history, backlinks, and dashboards via Dataview and Tasks.
    

### Note-taking patterns

- Use citations and tags for “Future Plans” and “Personal Revelations.”
    
- Timestamping journal entries improves later retrieval; theme tweaks can show times clearly.
    

## Conclusion

Next actions:

# What a Senior React Developer Should Know
## Checklist
- **Refactors**: what to improve next time; what you’d do differently.
- **Testing**: cover visuals (e.g., breaking BEM layout), behaviour, and type safety.
- **Performance hooks**: know when to use `useCallback`, `useMemo`, and `React.memo`.
- **MobX interop**: best practices for `observer` / `inject`; when to prefer hooks-based patterns.
- **Prioritization**: use visual aids (e.g., `Prioritize-wisely.png`) to focus work.

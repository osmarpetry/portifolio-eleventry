# French Vocabulary & Study Ritual

## 🗣 Expressions to internalize
- **mal du pays** — homesickness; melancholic longing for a past time or unexperienced place.
- **nostalgie de l'enfance** — yearning for childhood; pair with personal anecdotes to build emotional context.
- Practice gendered forms: *ces émotions* (these emotions), *cette émotion* (this emotion).

## 📖 Study workflow
1. **Collect** interesting phrases during media consumption and tag them by emotion.
2. **Create** Anki cards with sentence-level cloze deletions (French front, contextual translation back).
3. **Review** using spaced repetition; record yourself pronouncing the phrases and compare to native audio.

## 🌐 Immersion prompts
- Watch ARTE documentaries; pause whenever a speaker describes sentiment, transcribe the sentence, and mimic cadence.
- Join language exchanges on Tandem focusing on emotional storytelling; request feedback on nuance.

## 🧠 Retention tips
- Map each emotion to a memory palace location (e.g., childhood bedroom for *mal du pays*).
- Write short journal entries describing daily moods using the target phrases.

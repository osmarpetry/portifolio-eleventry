# How to Learn — Go TDD & LeetCode focus

## 🚀 Kick-off ritual for Go practice
- Begin every Go project or kata with **TDD**.
- Reference video walkthrough: [https://youtu.be/LhuODuK44OU](https://youtu.be/LhuODuK44OU)
- Use the same red → green → refactor rhythm to stay consistent.

## 🧠 LeetCode fundamentals to master
- `#binary-tree`
- `#list`
- `#hashmap`

Focus interview drills on these three structures; expand only after they feel automatic.

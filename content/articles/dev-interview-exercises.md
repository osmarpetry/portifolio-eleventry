# Interview Practice Notes

## 1. Goals & Process
1. Understand the problem context and purpose before coding.
2. Plan how to solve it (tools, data structures, algorithms).
3. Practice implementation to reinforce knowledge.
4. Refine afterwards—apply theory, optimize complexity, follow best practices.

## 2. Problem translation
- Convert real-world or whiteboard problems into abstract models.
- Identify essential elements, relationships, and choose appropriate data structures/algorithms.

## 3. Data ordering
- Check if input data is already sorted; affects algorithm choice (binary search vs sorting first).

## 4. Worst-case analysis
- Prioritize worst-case complexity (time/space) to ensure performance under adverse conditions.
- Predictable worst-case behaviour is crucial in mission-critical contexts.

## 5. Data locality
- Consider where data resides; optimize access via indices, hash tables, or precomputed locations.

## Summary
- **Understand** → **Abstract** → **Select algorithm** → **Practice & refine**.
- Emphasize worst-case scenarios and data organization for robust solutions.
